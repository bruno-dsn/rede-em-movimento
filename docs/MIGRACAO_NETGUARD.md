# Um laboratório de redes e cibersegurança

O NetGuard atual é um produto empresarial. Seu acervo educacional v6 foi preservado aqui, a pedido de Bruno, antes da separação.

- `cyber/index.html`: acesso organizado aos fundamentos, missões, logs, Wi-Fi e demonstração operacional arquivada.
- `cyber/fundamentos.html`: 27 aulas / nove assuntos; aceita o progresso `netguard-academy` v1 sem mudar seu formato.
- `labs/netguard-v6`: 156 arquivos byte a byte do commit `cff8e01201c215fdc5b6cadf95d1c3c7f3eaf140`. `MIGRATION.json` registra tamanho, SHA-256 e hash Git de cada arquivo. Apenas a identidade de hospedagem `.openai/hosting.json` foi excluída.

## Executar práticas locais

Abra a pasta `labs/netguard-v6` no VS Code e siga seu README ou `docs/FUNDAMENTOS.md`. Python 3.12+; exercícios básicos usam a biblioteca padrão. Os servidores de demonstração são restritos a 127.0.0.1 e devem usar dados fictícios. O acervo mantém o nome NetGuard onde necessário para preservar a versão histórica, CLI e formatos. Não é a versão atual do produto.

As 43 aulas de formação e 29 aulas de revisão de redes continuam intactas. Cada caderno conserva seu formato e sua própria importação. Exporte notas antes de fechar. Nenhum livro comercial foi copiado ou redistribuído.
